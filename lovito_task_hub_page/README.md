# Lovito 任务中心 GitHub Pages

这是 Lovito 任务中心的静态介绍页，用于 GitHub Pages 部署。

## 本地预览

可直接打开 `index.html` 进行本地预览。

## GitHub Pages

如果将本目录作为独立仓库发布：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/`

如果继续保留在当前多项目仓库中，可以通过 GitHub Actions 发布本目录，或将本目录内容同步至仓库 `/docs` 目录后选择 `/docs` 发布。

下载按钮当前为样式占位，后续将 `index.html` 中 `#download` 区域的链接替换为正式安装包地址即可。
