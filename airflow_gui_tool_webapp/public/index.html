使用指南

第一次打开会自动展示；之后可通过右上角“帮助”再次查看。

Lovito Task Hub

把常用 Airflow 操作收进一个轻量窗口

这里可以筛选 DAG、触发任务、查看 runs / tries / logs，也可以在任务运行后关闭程序，之后再回来继续看日志。

顶部区域

服务下拉：切换不同 Airflow 服务地址。

Owner：按负责人过滤 DAG，默认 Shaun。

重连：手动重新登录并刷新 cookie。

刷新：重新加载 DAG 列表和远端 conf 配置。

DAG 列表

分类按钮：按 tag 快速筛选 Paid Ads、Listing、买手、其他。

搜索框：按 DAG 名称、描述、tag 搜索。

左侧开关：启用或暂停 DAG，仅系统用户 shaun.pan 可操作。

触发任务

dag_run_id：不填会自动使用系统用户名加当前时间生成。

dag_run conf：有专属 fields 的 DAG 按输入框填写；没有 fields 的 DAG 可以不用填，保留默认 {} 即可。

Trigger：触发前会检查当前 running / queued 任务，超过 3 个会弹窗提醒。

Recent Runs

展示最近运行记录，点击某条 run 可切换到对应任务详情。

run conf 会以摘要展示，点击摘要或复制按钮可打开大窗口查看并复制完整 JSON。

Task Tries

展示当前 run 下 task 的尝试记录，点击不同 try 可以切换查看对应日志。

这里适合排查重试、失败后重跑、以及同一 task 不同尝试之间的差异。

Task Log

跟随当前 task：选择 run 后自动追踪当前最需要关注的 task。

自动滚动：日志刷新后保持在底部。

搜索日志：点击放大镜或按 Ctrl / ⌘ + F 打开搜索；Enter 下一个，Shift + Enter 上一个。

刷新 / 终止 / 清空：分别用于拉取日志、终止当前 task、清空当前窗口显示。

任务运行不依赖这个窗口

Trigger 后任务是在 Airflow 服务器上运行，不是在本地 GUI 里运行。你可以关闭程序，之后再次打开会自动恢复到上一次查看的 DAG / run / task log 位置，继续追踪运行结果。
